# Flower Delivery Service

Онлайн-сервис доставки цветов с расчётом стоимости и сроков доставки по адресу в реальном времени.

## Проблема

Покупателям неудобно заказывать цветы вручную через соцсети или по телефону — нет единого каталога, а стоимость и сроки доставки становятся известны только после согласования с флористом. Сервис даёт витрину букетов с фильтрацией и мгновенным расчётом доставки на этапе оформления заказа.

## Тема проекта

Онлайн-сервис доставки цветов с интеграцией внешнего API расчёта стоимости и сроков доставки.

## Стек технологий

- **Backend:** Python (FastAPI)
- **База данных:** PostgreSQL
- **Frontend:** React
- **Внешняя зависимость:** API расчёта стоимости и сроков доставки (СДЭК / Boxberry / Яндекс.Доставка)
- **Контейнеризация:** Docker, Docker Compose
- **CI:** GitHub Actions

## User Stories

1. Как покупатель, я хочу отфильтровать букеты по цене и поводу, чтобы быстро найти подходящий вариант.
2. Как покупатель, я хочу увидеть точную стоимость и срок доставки по моему адресу перед оплатой, чтобы не тратить время на заказы, которые окажутся слишком дорогими или долгими.
3. Как покупатель, я хочу видеть историю своих заказов, чтобы отслеживать покупки.
4. Как покупатель, я хочу получить уведомление, что заказ оформлен, даже если сервис расчёта доставки временно недоступен.

## Архитектура

> Раздел будет заполнен на Этапе 3: диаграммы C4 (Context, Container), ER-диаграмма БД, контракты API, расчёт нагрузки (R/W-соотношение, сетевой трафик, объём хранения за 5 лет), стратегия масштабирования до 100 000 пользователей/сутки.

## Отказоустойчивость

> При недоступности внешнего API расчёта доставки: кэш последних котировок по региону, fallback на фиксированный тариф, Circuit Breaker на повторные запросы.

## Установка и запуск

```bash
docker-compose up
```

> Одной командой поднимаются: PostgreSQL + миграции, backend, frontend, прогон тестов с выводом отчёта. Инструкция будет дополнена на Этапе 6.

## Тестирование

> Unit-тесты бизнес-логики (фильтрация, сортировка, расчёт корзины, расчёт доставки) — Этап 5.
> Интеграционный/E2E-сценарий: логин → каталог → фильтр → корзина → оформление заказа → история заказов.
